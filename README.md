# GreenAir AI

GreenAir AI is a project I built to understand and analyze air quality data.

The application helps users explore pollution data, view air quality trends, and get insights through an AI-powered assistant.

## Features

- View air quality data and trends.
- Import data from supported sources.
- Explore pollution levels for different locations.
- Analyze air quality using machine learning.
- Get insights through an AI assistant.

## Technologies Used

- React, TypeScript, Vite
- Python, FastAPI
- Machine Learning
- SQLite
- Air quality data APIs

## Running the Project

Clone the repository:

```bash
git clone https://github.com/susa2003/GreenAir-AI.git
cd GreenAir-AI
```

Install the frontend and backend dependencies using the project configuration files. Configure the required environment variables before starting the application.

I built this project to learn more about air quality analysis, machine learning, and AI-based applications.
